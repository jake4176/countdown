# 노랑조명 편집 스킬

시작 전에 이 파일 전체를 읽고, 특히 '절대 규칙'은 하나도 빼지 말고 지킨다.

## 절대 규칙 (사용자가 준 피드백. 날짜순으로 계속 추가)
- 2026-10-31 · 화면은 실제 사이트 캡처·실제 촬영본만 쓴다. 목업 카드·가짜 터미널·AI로 만든 조명 사진 금지.
- 2026-10-31 · 조명 색감은 보정으로 바꾸지 않는다. 전구색(2700~3000K)·주백색(4000K)·주광색(6500K)이 실제와 다르게 보이면 고객 클레임이 난다.
- 2026-10-31 · 맨 위 제목은 첫 화면부터 고정한다. 흐릿하게 나타나지 않게.
- 2026-10-31 · 자막은 단어가 나오는 순간에 하나씩. 강조 단어는 노란색(#FFC400) + 검은 외곽선.
- 2026-10-31 · 한 화면을 1.5초 넘게 가만히 두지 않는다(줌·하이라이트·칩 등장).
- 2026-10-31 · 첫 1초 안에 결과(불 켜진 공간)를 먼저 보여준다. 설명은 그다음.
- 2026-10-31 · 자막·제목 한국어는 번역체 금지("~에 대한", "~로부터의", "그의/그녀의"). 말하듯 짧게 쓴다.
- 2026-10-31 · 화면 하단 220px, 오른쪽 140px에는 글자를 두지 않는다(인스타·유튜브 UI에 가림).
- 2026-10-31 · "이름은 그대로 두고" → 줄자·자재 라벨의 '노랑조명 김태정' 이름은 가리지 않는다(개인 정보 검사 예외).
- 2026-10-31 · 맨 위 고정 제목은 진행바와 로고를 피하고, 화면 속 간판·상호를 가리지 않는 높이에 둔다. 엔딩카드에서는 뺀다.

## 순서
1. 받아쓰기: `whisper 파일 --model medium --language ko --word_timestamps True --output_format json`
   `--initial_prompt "노랑조명, 전구색, 주백색, 주광색, 색온도, 레일조명, 펜던트, 매입등, 다운라이트, 스마트스토어"`를 붙여 조명 용어 오인식을 줄인다. 받아쓴 뒤 제품명·숫자(W, K, 평)는 사람 말 기준으로 한 번 더 확인한다.
   → 결과에서 단어마다 `{word, start, end}`만 뽑아 `words.json`으로 저장.
2. 쉼 줄이기: `python3 scripts/cut_pauses.py 입력 cut.mp4` (기본값: 0.18초 넘는 쉼은 0.12초만 남김, 목소리 속도는 그대로)
   → 컷 뒤에는 시각이 바뀌므로 **cut.mp4로 1번 받아쓰기를 다시** 해서 words.json을 새로 만든다.
3. 화면 캡처: 문장마다 말하는 사이트(스마트스토어 상세페이지, 네이버 플레이스 등)를 Puppeteer/Playwright로 실제로 열어 캡처한다.
   강조할 문구의 좌표(getBoundingClientRect)는 **캡처와 같은 실행에서** 뽑는다. 따로 재면 하이라이트가 밀린다.
4. 조립: `/hyperframes`로 1080x1920 세로 영상. words.json 시각에 맞춰 자막·캡처 창·하이라이트를 배치한다.
5. 렌더 후 소리 맞추기: `python3 scripts/normalize.py render.mp4 final.mp4` (두 번 재서 맞춤. 한 번만 돌리면 1~2 LU 빗나간다)
6. 검사: `python3 scripts/check_render.py final.mp4 --ref cut.mp4`
   - 입 모양 싱크: 원본 대비 시차 0ms(±20ms 이내)
   - 개인 정보: 0.5초마다 화면 글자를 읽어 이메일·전화번호·API 키·UUID·주문번호가 보이면 실패
   - 소리 크기: -14 LUFS(±1)
   하나라도 실패하면 고치고 다시 렌더한다. **검사 통과 전에는 사용자에게 보여주지 않는다.**

## 피드백 받는 법
사용자가 고칠 점을 말하면, 고친 뒤 위 '절대 규칙'에 `- YYYY-MM-DD · 사용자가 한 말 그대로` 형식으로 한 줄 추가한다.
비슷한 규칙이 이미 있으면 새로 쓰지 말고 그 줄을 고친다(규칙이 서로 부딪히면 최신 것이 이긴다).
