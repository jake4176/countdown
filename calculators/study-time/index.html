공부 시간 계산기

공부할 분량과 세션 길이로 세션 수·총 시간·소요 일수를 계산합니다.

어떻게 계산하나요?

총 공부 시간을 세션 길이로 나눈 뒤 올림해 세션 수를 구하고, 세션 사이의 휴식을 더해 실제 소요 시간을 계산합니다. 하루에 공부할 수 있는 시간을 입력하면 며칠이 걸리는지도 함께 알려 줍니다. 시험이 정해져 있다면 시험 카운트다운과 함께 쓰면 하루 계획을 세우기 좋습니다.

자주 묻는 질문

공부 세션 수는 어떻게 나오나요?

공부할 총 시간을 세션 한 번의 길이(기본 30분)로 나눈 뒤 올림합니다. 예를 들어 총 3시간을 30분 세션으로 하면 6번의 세션이 됩니다.

며칠 걸리는지는 어떻게 계산하나요?

하루에 공부할 수 있는 시간을 입력하면, 총 공부 시간을 그 값으로 나눠 올림한 일수를 보여 줍니다. 하루 가용 시간을 비워 두면 일수는 계산하지 않습니다.

세션 길이는 얼마가 좋나요?

정답은 없습니다. 집중이 자주 끊기면 25분, 흐름이 이어지면 30~50분이 무난합니다. 값을 바꾸면 세션 수와 총 시간이 다시 계산되니 비교해 보세요.
