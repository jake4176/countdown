프로젝트 시간 계산기

전체 작업 시간과 하루 가용 시간으로 완료까지 걸리는 일수와 예상일을 추정합니다.

어떻게 계산하나요?

전체 작업 시간을 하루 작업 시간으로 나눈 뒤 올림해 작업일수를 구하고, 주당 작업일로 나눠 몇 주가 걸리는지 계산합니다. 완료 예상일은 오늘부터 주말·비작업일을 단순히 건너뛴 대략치입니다. 큰 프로젝트라면 하루치를 타임블로킹과 작업 세션 플래너로 잘게 나눠 실행해 보세요.

자주 묻는 질문

완료 일수는 어떻게 계산하나요?

전체 작업 시간을 하루 작업 시간으로 나눈 뒤 올림해 작업일수를 구합니다. 예를 들어 40시간을 하루 8시간으로 하면 5일이 됩니다.

완료 예상일은 정확한가요?

주당 작업일을 반영해 주말·비작업일을 단순히 건너뛴 대략치입니다. 공휴일이나 중단은 반영하지 않으므로, 여유를 두고 계획하시길 권합니다.

주당 작업일은 어떤 의미인가요?

한 주에 며칠 작업하는지를 뜻합니다. 5로 두면 평일만 작업한다고 보고 주 단위 소요와 완료 예상일을 계산합니다.
