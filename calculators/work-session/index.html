작업 세션 플래너

시작 시각과 세션 구성을 넣으면 휴식까지 포함한 하루 일정표를 만들어 줍니다.

어떻게 만들어지나요?

시작 시각부터 세션 길이만큼 집중 구간을 배치하고, 세션 사이에 휴식을 넣습니다. 긴 휴식 주기를 정하면 그 주기마다 긴 휴식이 들어갑니다. 완성한 일정을 실제로 실행할 때는 타이머의 직접 설정으로 각 세션 길이를 맞춰 사용할 수 있습니다.

자주 묻는 질문

일정표는 어떻게 만들어지나요?

입력한 시작 시각부터 세션 길이만큼 집중 구간을 넣고, 세션 사이마다 휴식을 배치합니다. 긴 휴식 주기를 정하면 그 주기마다 긴 휴식이 들어가고, 마지막 세션 뒤에는 휴식을 넣지 않습니다.

긴 휴식 주기를 끄려면 어떻게 하나요?

긴 휴식 주기를 0으로 두면 모든 휴식이 짧은 휴식으로 처리됩니다. 포모도로처럼 4번째마다 길게 쉬고 싶다면 4로 설정하세요.

종료 시각이 자정을 넘어가면 어떻게 표시되나요?

다음 날로 넘어가는 시각은 (+1d)처럼 며칠 뒤인지 함께 표시됩니다. 심야 작업 계획을 세울 때 참고하세요.
