# ⏳ Timer

다국어·반응형 카운트다운 타이머 + 스톱워치 웹사이트.
60분·30분 프리셋, 직접 시간 입력, 완료 알림음을 지원합니다.

## 특징

- **카운트다운 모드** — 프리셋(5/15/30/60분) 또는 분·초 직접 입력으로 시간 설정 → 0까지 감소
- **스톱워치 모드** — 0부터 정방향 증가
- **완료 알림** — 0 도달 시 비프음 3회 + 화면 깜빡임 + 완료 메시지 (Web Audio API, 오디오 파일 없음)
- **진행률 링** — 카운트다운 진행에 따라 줄어드는 글로우 링
- **스탑워치식 조작** — 시작/일시정지 토글, 리셋. 스페이스바=시작/정지, R=리셋
- **다국어** — 한국어·English·Español·日本語·中文 (브라우저 언어 자동 감지 + 수동 전환)
- **미니멀 다크 + 글로우** 디자인, 데스크탑/모바일 반응형
- **빌드 없음** — 순수 HTML/CSS/JS, 의존성 없음

## 실행

```bash
npm run dev     # 개발 서버 → http://localhost:3001
npm test        # 순수 로직 자동화 테스트 (Node 내장 러너)
```

> ES 모듈을 사용하므로 로컬 확인 시 서버 필요 (`npm run dev`). `index.html`을 직접 열면 모듈 로드가 차단됩니다.

## 배포

아래 5개 파일을 정적 호스트(GitHub Pages, Netlify, Vercel, Cloudflare Pages 등)에 업로드. 빌드 단계 불필요.

```
index.html  styles.css  core.js  locales.js  app.js
```

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업 + `data-i18n` 다국어 매핑 |
| `styles.css` | 다크/글로우 디자인 토큰, 진행률 링, 반응형 |
| `core.js` | 순수 로직: 시간 포맷·파싱 (테스트 대상) |
| `locales.js` | 5개국어 문자열 + i18n 헬퍼 (테스트 대상) |
| `app.js` | 타이머 상태머신·모드·알림음·링 렌더링 |
| `serve.mjs` | zero-dep 개발용 정적 서버 |

## 조작

- **프리셋 버튼** — 5/15/30/60분 원클릭 설정 (카운트다운 모드)
- **직접 입력** — 분·초 숫자 입력 (입력 즉시 반영, 카운트다운 모드)
- **시작/일시정지** — 한 버튼으로 토글
- **리셋** — 설정 시간(카운트다운) 또는 0(스톱워치)으로 복귀
- **키보드** — `Space` 시작/정지, `R` 리셋
