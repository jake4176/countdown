# 글로벌 카운트다운 웹사이트 — 설계 문서

**날짜**: 2026-07-12
**상태**: 승인됨 (Approach A)

## 1. 개요

사용자가 직접 이벤트를 설정해 카운트다운하는 글로벌 정적 웹사이트.
다국어(5개국어)와 시간대 자동 처리를 지원하며, URL 공유로 전 세계 누구나 같은 카운트다운을 자기 언어·시간대로 볼 수 있다.
빌드 단계 없는 정적 사이트로, 미니멀 다크 + 글로우 디자인을 적용한다.

## 2. 핵심 기능

1. **이벤트 설정**: 이름 + 목표 날짜/시간 입력 → 카운트다운 시작
2. **실시간 카운트다운**: 1초마다 갱신, 일/시/분/초 표시. 초 단위에 부드러운 전환 애니메이션
3. **공유**: 이벤트 정보를 URL 쿼리 파라미터로 인코딩한 링크 복사. 링크를 연 사람은 자기 언어로 즉시 동일 카운트다운 확인
4. **저장**: localStorage에 저장되어 새로고침 후에도 유지
5. **종료 처리**: 0:0:0:0 도달 시 축하 메시지로 전환

## 3. 글로벌 처리

### 시간대
- 생성 시 사용자 현지 시간(브라우저 시간대)으로 입력받은 날짜/시간을 **절대 UTC 시각**으로 변환해 저장
- 남은 시간 = `targetUTC - nowUTC` 로, **시청자 위치와 무관하게 전 세계 동일**
- 이벤트 목표 시각 표시는 시청자 현지 시간대로 변환 (`Intl.DateTimeFormat`)
- 공유 시: URL에는 UTC ISO 문자열만 담기므로, 각 시청자의 시간대가 자동 반영됨

### 다국어 (i18n)
- 지원 언어: **KO, EN, ES, JA, ZH** (구조상 추가는 객체 1개 추가로 끝)
- 자동 감지: `navigator.language` 우선 매칭, 없으면 EN 폴백
- 수동 토글: 우상단 언어 선택기, 선택값은 localStorage에 저장
- 번역 대상: 버튼 라벨, 라벨(일/시/분/초), 안내/축하 메시지, 설정 모달 필드 라벨, placeholder
- 숫자/날짜 포맷: `Intl.NumberFormat`, `Intl.DateTimeFormat`로 각 언어에 맞게 표시

## 4. 디자인 시스템 — 미니멀 다크 + 글로우

| 토큰 | 값 |
|---|---|
| 배경 | `#0a0a0f` + 중앙 방사형 미세 그라데이션 |
| 강조색(Primary) | `#7c5cff` (보라 인디고) |
| 카드 배경 | `rgba(255,255,255,0.04)` + 미세 보더 |
| 본문 텍스트 | `#f5f5f7` |
| 보조 텍스트 | `rgba(245,245,247,0.5)` |
| 글로우 | 숫자/카드에 `text-shadow`/`box-shadow` 적용 (강조색, 낮은 불투명도) |
| 폰트 | 모던 산세리폰 시스템 폰트 스택 (`-apple-system, 'Segoe UI', Roboto, sans-serif`). 외부 웹폰트 의존성 없음 (속도·단순성 우선) |

- 숫자 4칸(일/시/분/초) 카드 레이아웃
- 초 칸 틱마다 부드러운 fade/slide 전환
- 상단: 이벤트 이름(큰 글씨) + 목표 시각(흐린 글씨)
- 우상단: 언어 토글. 하단 중앙: "이벤트 설정" / "공유" 버튼

### 반응형
- 데스크탑: 숫자 4칸 가로 배치
- 모바일: 숫자 축소 또는 2×2 재배치, 버튼 풀폭
- 중단점: `768px` 기준

## 5. 파일 구조

```
countdown/

├── styles.css      # 다크/글로우 디자인, 반응형
```

빌드 단계 없음. 어떤 정적 호스트(GitHub Pages, Netlify, Vercel)에도 즉시 배포 가능.

## 6. 컴포넌트 / 책임 분리

### `app.js`
- **State**: 현재 이벤트 객체 `{ name, targetISO }`, 언어 코드
- **카운트다운 루프**: `setInterval` 1초. 남은 시간 계산 → DOM 갱신
- **시간대 변환**: 입력 현지 시간 → UTC ISO. 표시용 현지 시간 포맷
- **공유**: 이벤트 객체를 URL 쿼리로 인코딩/디코딩 (`encodeURIComponent` + Base64)
- **저장**: localStorage read/write
- **언어**: 언어 변경 시 전체 UI 문자열 갱신
- **상태 전환**: 설정 전 / 카운트다운 중 / 종료됨

### `locales.js`
- `translations = { ko: {...}, en: {...}, es: {...}, ja: {...}, zh: {...} }`
- `t(key, lang)` 헬퍼, 폴백 EN
- 라벨 키 목록: `eventTitle, targetTime, days, hours, minutes, seconds, setEvent, share, eventName, selectDateTime, save, cancel, expiredMessage, shareCopied, noEventPrompt`

### `index.html`
- 의미론적 구조: header(로고+언어토글), main(이벤트 타이틀, 카운트다운 카드들, 버튼), 설정 모달
- 모든 표시 문자열은 `data-i18n` 속성으로 i18n 키 매핑

### `styles.css`
- CSS 변수로 디자인 토큰 관리 (강조색 등 한 곳에서 교체 가능)
- 글로우, 카드, 반응형, 모달 스타일

## 7. 데이터 흐름

```
[사용자 입력] → 현지 시간 → UTC ISO 변환
                            ├→ localStorage 저장
                            └→ (공유 시) URL 쿼리 인코딩

[페이지 로드]
  1. URL 쿼리에 이벤트 있음? → 디코딩 → 사용
  2. 아니면 localStorage? → 사용
  3. 둘 다 없음 → "이벤트 설정" 유도 안내

[카운트다운 루프] 1초마다
  targetUTC - nowUTC → 일/시/분/초 분해 → DOM 갱신
  ≤ 0 → 종료 메시지 전환
```

## 8. 에지 케이스

- **과거 날짜 선택**: 즉시 "종료됨" 상태로 표시
- **공유 링크에 이벤트 정보 없음**: 안내 메시지 + 설정 유도
- **잘못된 입력**(이름 없음/날짜 없음): 저장 막고 필드 하이라이트
- **시간 만료 중 루프**: 종료 상태로 1회 전환 후 루프 정지
- **URL 디코딩 실패**: 안내 메시지 + 설정 유도(손상된 링크 대응)
- **지원 언어 아님**: EN 폴백

## 9. 테스트 / 검증

수동 검증 항목 (정적 사이트, 자동화 테스트 프레임워크 없음):
1. 이벤트 설정 → 카운트다운 정상 표시, 초 단위 갱신
2. 새로고침 후 이벤트 유지
3. 공유 링크 복사 → 시크릿 창에서 열었을 때 동일 카운트다운 표시
4. 언어 토글 → 모든 문자열 즉시 전환, 날짜/숫자 포맷 변경
5. 모바일 뷰포트에서 레이아웃 깨짐 없음
6. 과거 날짜 → 종료 상태
7. 만료 시점 도달 → 축하 메시지 전환
